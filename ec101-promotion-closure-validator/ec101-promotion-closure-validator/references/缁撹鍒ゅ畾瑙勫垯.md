# 结论判定规则

结论只能使用以下四个值。

| 结论 | 判定 |
|---|---|
| 支持 | 活动规则、订单命中、理论权益、实际权益、销售和履约均可验证，且没有影响结论的 P0 缺口 |
| 条件支持 | 核心活动执行可验证，但最终费用仍依赖明确的售后、成本、费用归属或其他条件 |
| 暂不支持 | 关键关系或数据缺失，无法可靠完成活动归因或费用重算 |
| 未验证 | 没有足够样本或尚未执行对应测试 |

## 汇总原则

总结果必须由四份支撑材料汇总产生。不得先填写结论再寻找证据。某项活动执行结果为“支持”，不等于最终费用闭环必然为“支持”。
