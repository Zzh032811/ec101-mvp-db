# 平台操作手册标准

## 用途

平台操作手册记录“如何稳定取得正确数据”，不是活动规则或某次验证的唯一事实来源。活动规则、期间和验证范围以活动任务卡及其配置证据为准。

## 每个平台/模块至少记录

| 字段 | 说明 |
|---|---|
| 平台、经销商 | 明确适用范围 |
| 模块/资料类型 | 客户、商品、订单、销售、活动执行、活动配置、售后费用等 |
| 导航路径 | 系统菜单到导出或查看位置 |
| 导出日期字段 | 下单时间、完成时间、出库时间等，必须说明业务含义 |
| 必选筛选条件 | 状态、活动、客户、商品、时间等 |
| 导出限制 | 单次日期范围、分页、历史可得性、空表风险等 |
| 输出形态 | 文件格式、是否需要截图、活动明细的行粒度 |
| 已知限制与验证日期 | 例如“无订单状态”“活动明细仅按商品行导出” |
| 证据位置 | 截图、操作视频或说明文件位置 |

## 安全边界

不在操作手册、活动任务卡、Skill 输入包或输出报告中保存账号、密码、验证码、Cookie 或其他登录凭据。凭据应保存在公司批准的受控工具中。
