# EC101 标准字段字典 V1

标准字段是 Skill 的统一中文业务语言，不要求平台修改原始表头。

来源类型：`平台原始`、`Skill计算`、`人工确认`。重要度：P0 影响活动或费用闭环；P1 影响判断准确性；P2 为辅助信息；P0* 表示活动存在该规则时为 P0。

字段映射表的展示范围不是本字典字段的交集或抽样，而是：`经销商各模块原始字段全集 ∪ EC101 V1 标准字段全集`。经销商提供但未纳入 V1 的字段仍须逐项保留并标记为 `非V1字段`；V1 要求但经销商未提供的字段也须逐项列出，并按实际情况标记为 `Gap`、`人工确认` 或 `可计算`。因此，本字典定义 EC101 的标准字段要求，但不限制字段映射表对经销商原始字段的完整展示。
