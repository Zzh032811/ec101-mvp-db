# 快马平台规则 V1

## 文件格式

快马导出的 `.xls` 可能实际为三种格式：

- OOXML：客户、商品和销售明细；使用 `openpyxl`。
- BIFF：订单明细；使用 `xlrd`。
- HTML Excel：活动明细；读取 HTML 表格，不按 BIFF 处理。

必须根据文件签名识别，不能只看扩展名。

## 关键关联

- 订单明细.`订单编号` = 销售明细.`单据编号`。
- 订单明细.`订单编号` = 活动明细.`订单号`。
- 订单明细.`客户编号` = 客户列表.`客户编号`。
- 订单明细.`商品编号` = 商品列表.`商品编号`。

## 状态与支付

- 本案例发放条件：订单状态为 `已完成`。
- 支付状态为独立维度，不作为发放过滤。
- `货到付款 + 未支付` 不能直接解释为未收款；输出“线下实收无法确认”。
- 活动明细中的状态列可能是后续查找补入值，最终仍需与订单明细精确核对。

## 输出约束

输出顺序固定为总能力矩阵、单平台验证报告、业务规则与待确认事项、最小数据要求与 Gap、标准字段映射。不能用支付状态筛掉订单，也不能把活动前订单解释为导出截断。
